## Verdict

**gemma4:26b is the better default chat slot for this hardware**, full stop:

- Quality gap to 31b is **2.4 percentage points** (1 extra failure on 42 tests).
- Speed advantage is **~3.3×** (110 tok/s vs 33).
- Both have identical SWA architecture and (in eval-006) identical hybrid MoE detection (8/128 active in our `bench.py` run).
- 26b at 131k context fully on GPU at 126 tok/s (validated in earlier bench session); 31b can't reach that throughput at any context.

If you want maximum eval depth and don't care about latency: 31b. For interactive use, batch evaluation, or anything where iteration speed matters: **26b is the obvious choice**.

Updated slot recommendations across the suite:
- **General chat / quick coding** → gemma4:26b (newly preferred — was 31b in eval-004)
- **Architecture deep-dives** → gemma4:31b (when speed doesn't matter)
- **Long-context code review (100k+)** → nemotron-3-nano:30b (eval-005, 786k @ 22 tok/s)
- **Bug-finding sharpness** → qwen35-coder or gemma4:26b (both 75%+ on debug tier)
