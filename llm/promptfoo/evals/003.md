## Rubric changes made after this eval

Three targeted fixes applied before next calibration run:

1. **Kotlin type system**: Removed Go comparison requirement from `[expert] type system depth`. Go isn't mentioned in the prompt — requiring the contrast was setting an arbitrary bar. Now just checks for Kotlin null safety / sealed classes as compile-time bug prevention.

2. **Variable schema**: Removed `[expert] indexing differences` assertion (GIN vs MongoDB). The prompt asks about the PostgreSQL vs MongoDB decision given variable schema — indexing internals aren't a natural part of that answer unless prompted. One focused test with one focused assertion is better.

3. **Queue vs HTTP: sync/async**: Loosened `[baseline] sync vs async as primary driver` from prescribing the conclusion ("HTTP is usually the right answer") to testing the insight — does it identify synchrony as the primary axis, ahead of throughput/durability/cost?
