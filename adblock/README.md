# AdGuard Home

Network-wide DNS ad blocker. Blocks ads and trackers at the DNS level for all devices on the network — no client-side setup required.

Admin UI at: https://adblock.jasonfagerberg.duckdns.org

## Notes

- DNS runs on port 53 — router must point to server IP (`192.168.50.186`) as primary DNS
- All devices on the network get ad blocking automatically
- Blocklists and query logs managed via the web UI
